# Antigravity Claude Desktop Skin + 简体中文汉化引擎

专为 **Antigravity 2.0 桌面端** 定制的 **Claude 羊皮纸暖白 + 中西文人文衬线（书卷风）主题皮肤 + 简体中文全量界面汉化引擎**（融合 [`Silas-02/antigravity-desktop-cn`](https://github.com/Silas-02/antigravity-desktop-cn) 并补齐 Antigravity v2.22.0+ 新增词条）。

---

## 1. 视觉、排版与中文汉化设计

### 色彩体系（羊皮纸暖白 & 深色暖炭黑）
| 界面区域 | 颜色值 | 视觉效果说明 |
| :--- | :--- | :--- |
| **主对话背景与顶部栏** | `#FAF9F5` | 温润羊皮纸暖白，消除刺眼冷白光 |
| **左侧边栏与用户提问气泡** | `#F0EEE6` | 暖亚麻灰米色，柔和区分功能层级 |
| **底部聊天输入框** | `#EFECE3` / `#FDFCF8` | 微暖象牙白悬浮卡片，聚焦时带有暖橙微光 |
| **品牌强调色（Claude 赤陶橙）** | `#D97757` / `#C6613F` | 按钮、开关、加载微光与超链接高亮 |
| **代码块与行内代码** | `#F4F2EA` / `#EAE7DD` | 暖砂岩卡片配 `#9A3E20` 赤陶深褐行内代码 |
| **深色模式兼容** | `#1F1E1D` / `#161514` | 自动适配 Claude 风格深色暖炭黑模式 |

### 字体与排版体系（离线内嵌，零外部网络依赖）
- **AI 回复正文与标题（人文衬线体）**：
  - 内置离线 `Source Serif 4` 可变衬线字体，搭配系统思源宋体 / 华文中宋，中英文混排自然舒适。
- **界面按钮与用户提问气泡（现代无衬线体）**：
  - 采用 `Inter` / `Segoe UI` / `Microsoft YaHei`，形成 **“你的提问现代干练、AI 的回答温润如书”** 的阅读层次。
- **代码块与终端（等宽字体）**：
  - 采用 `Cascadia Code` / `JetBrains Mono` / `Consolas`，严格跳过汉化转换，确保代码零污染。

### 简体中文全量汉化体系
- **2,126+ 条翻译词条**：涵盖主界面、左侧导航栏、设置页、工具调用状态提示、相对时间显示等全部常见界面文本。
- **原生菜单与系统托盘汉化**：通过外置主进程钩子自动翻译顶部菜单栏、右键菜单与右下角系统托盘菜单，无需修改或解包官方 `app.asar` 文件。

---

## 2. 无损安装与官方更新自愈机制

- **零破坏外置引导**：通过 `resources/app/index.js` 外置引导启动，保持官方 `app.asar` 原文件字节完全不变。
- **自动更新恢复**：后台守护进程（`Antigravity Claude Skin Guardian`）会在系统登录时自动运行，当检测到 Antigravity 完成官方版本更新后，会自动恢复外置启动引导与界面汉化注入，无需每次更新后手动重装。

---

## 3. 单独管理命令（PowerShell）

除使用仓库根目录的统一脚本 `..\install-all.ps1` 外，您也可以在本子目录中单独管理皮肤与汉化：

```powershell
# 单独安装 / 激活皮肤与中文汉化
.\install-claude-skin.ps1

# 修改样式 (src\claude-core.css) 或词库后实时热更新窗口
.\live-reload.ps1

# 单独卸载皮肤并实时还原官方默认英文界面
.\restore-default.ps1
```
